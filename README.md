# Student Record Manager

## About the Project
Student Record Manager is a simple C++ project created to practise programming concepts. It helps manage student names, marks, grades, and results.

## Features
- Enter details of 3 students
- Display student marks and grades
- Check pass or fail status through grades
- Calculate the class average
- Validate marks between 0 and 100
- Simple menu-driven interface

## Technologies Used
- C++
- GitHub

## How to Run
1. Download `student_manager.cpp`.
2. Open it in a C++ compiler or IDE.
3. Compile and run the program.
4. Follow the menu options displayed.
